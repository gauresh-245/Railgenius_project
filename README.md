# 🚆 RailGenius - Smart Railway Reservation

RailGenius is a full-stack railway travel management platform developed using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. The system enables users to search trains, book tickets, view train schedules, explore local and metro train services, check station information, and access travel-related services through an interactive user interface.

The project is designed to simplify railway travel by providing a centralized platform for reservation, ticket management, and train information.

# 🌟 Features

### 🎫 Train Ticket Booking

Users can search and book railway tickets by selecting source, destination, and travel date.

### 🚉 Local Train Management

Provides local train schedules, routes, station details, and fare information.

### 🚇 Metro Train Information

Displays metro train routes, station information, and travel details.

### 👤 User Authentication

Secure registration and login functionality for users.

### 💳 Ticket Confirmation System

Generates booking confirmation and passenger details after successful ticket booking.

### 🌦️ Weather Information

Integrated weather module to display weather conditions for travelers.

### 🍽️ E-Catering Services

Allows users to explore food and catering services during their journey.

### 🏖️ Holiday & Tourism Information

Provides travel and holiday-related recommendations for passengers.

### 📍 Station & Route Information

Displays train routes, station details, and travel information.

### 📱 Responsive Design

User-friendly interface compatible with desktop and mobile devices.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/gauresh-245/Railgenius_project.git
```

```bash
cd Railgenius_project
```

---

## Backend Setup

```bash
cd backend
npm install
npm start
```

Backend server will run on:

```text
http://localhost:5000
```

---

## Frontend Setup

Open another terminal:

```bash
cd frontend
npm install
npm start
```

Frontend will run on:

```text
http://localhost:3000
```
